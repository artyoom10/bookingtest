# AI Booking Assistant

Небольшой прототип интеграции языковой модели с данными бронирования. Пользователь
выбирает актуальный статус паспорта, вводит сообщение гостя и получает сгенерированный
Gemini ответ на русском языке.

Браузер обращается только к FastAPI backend. API-ключ Gemini не передаётся во frontend.
Справа отображается отладочная панель с фактическими параметрами запроса к модели и
содержательным ответом Gemini SDK. Транспортные headers и API-ключ в отладочные
данные не включаются.

## Стек

- Python и FastAPI
- официальный Google GenAI Python SDK (`google-genai`)
- HTML, CSS и vanilla JavaScript
- Gemini 3.1 Flash-Lite по умолчанию

## Локальный запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Активируйте виртуальное окружение:

```powershell
.venv\Scripts\Activate.ps1
```

Для macOS/Linux:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Создайте `.env` на основе `.env.example` и укажите ключ, полученный в Google AI Studio:

```dotenv
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-3.1-flash-lite
```

Запустите приложение:

```bash
uvicorn main:app --reload
```

Откройте <http://127.0.0.1:8000>.

## Сценарии проверки

1. Оставьте статус «Паспорт не получен» и отправьте «Как мне заселиться?». Ответ
   должен объяснить необходимость сначала предоставить паспорт и содержать тестовую
   ссылку `https://example.com/passport`.
2. Выберите «Паспорт получен» и отправьте «Что мне делать дальше?». Ответ должен
   подтвердить принятие паспорта и назвать оплату залога следующим этапом.

Дополнительно можно проверить вопросы «Где мне отправить паспорт?», «Какие следующие
действия?» и «Вы получили мой паспорт?» при обоих статусах.

## Переменные окружения

- `GEMINI_API_KEY` — обязательный API-ключ Gemini.
- `GEMINI_MODEL` — необязательный идентификатор модели; по умолчанию используется
  `gemini-3.1-flash-lite`.

Настоящий API-ключ нельзя добавлять в Git. Файл `.env` исключён через `.gitignore`.

## Деплой на Vercel

1. Импортируйте GitHub-репозиторий в Vercel.
2. В настройках проекта откройте **Settings → Environment Variables**.
3. Добавьте `GEMINI_API_KEY` и, при необходимости, `GEMINI_MODEL` для нужных окружений.
4. Запустите deployment. Конфигурация FastAPI находится в `vercel.json`.
